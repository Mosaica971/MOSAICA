# MOSAICA documentation

MOSAICA assigns each farm plot of a territory to **at most one crop**, so as to maximise the
risk-adjusted gross margin, under agronomic eligibility, per-farm rules and territorial
quotas. It is a large binary MILP (~309 000 variables for Guadeloupe 2017), solved by HiGHS
through Pyomo.

This repository is the **Python/Pyomo rewrite of an original GAMS model** (`context/gams/`).
The mandate is *parity*: the legacy behaviour is ported faithfully, bugs included, and every
deviation is deliberate and documented.

## Installation

```powershell
git clone <url>
python -m venv .venv                              # do NOT copy a .venv from another machine
.venv\Scripts\python -m pip install -e ".[dev]"   # dependencies + pytest (HiGHS via highspy)
.venv\Scripts\python -m pytest tests\test_readers.py   # check the install (~1 s)
```

`data/` is **not** in the repository (input tables, shapefiles): copy it separately. Without
it, everything touching the data fails; the unit tests still pass (they are data-free by
choice).

## External sources (`context/`)

- `context/gams/` — the original GAMS as `.txt`. **Source of truth for any parity question**:
  `MODELE.txt` (equations), `OPTIMISATION.txt` (computations), `ENTREES.txt` (derivations),
  `SETS.txt` (sets).
- `context/Chopin et al 2015 pour Hal.pdf` — the reference article. §2.6 defines the
  calibration method (PAD) and thresholds; Tables 1 and 2 the yields/margins and the
  risk-aversion coefficients.
- `context/Rapport technique variables MOSAICA_v2.docx` — variable dictionary (not versioned).
